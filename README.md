# Volunteer MAI Bot

Telegram-бот для волонтёров МАИ.

## Технологии
- Python 3.12
- aiogram 3
- Docker, Docker Compose

## Запуск

1. Клонировать репозиторий:
   ```bash
   git clone https://github.com/viktaim/volunteer-mai-bot.git
   cd volunteer-mai-bot
   ```
2. Создать файл `.env` из шаблона и заполнить значения:
   ```bash
   cp .env.example .env
   ```
   - `BOT_TOKEN` — токен бота. Получить у @BotFather в Telegram (для тестов создайте своего бота)
   - `PROXY_URL` — адрес прокси. Нужен только если Telegram недоступен без прокси, иначе оставьте пустым
3. Запустить:
   ```bash
   docker compose up -d --build
   ```
4. Посмотреть логи / остановить:
   ```bash
   docker compose logs -f
   docker compose down
   ```

Файл `.env` нельзя коммитить: токены и пароли в репозиторий не попадают.

## Ветки
- `main` — стабильная версия, она работает на сервере
- `develop` — сюда сливается всё готовое, тестировщик проверяет эту ветку
- `feature/название` — новая функция
- `fix/название` — исправление бага
- `docs/название` — документация

Ветки создаются от `develop`. Названия латиницей, через дефис.

## Правила работы с Pull Request
1. Каждая задача делается в отдельной ветке от `develop`.
2. Напрямую в `main` и `develop` не пушим, только через PR.
3. В PR пишем понятное название и коротко, что сделано.
4. Перед созданием PR подтягиваем свежий `develop` и проверяем, что бот запускается.
5. Нужен минимум 1 апрув от другого участника команды.
6. После слияния ветку задачи удаляем.
7. Перенос `develop` → `main` делается только после проверки тестировщиком.
